COMSPOC provides commercial off‑the‑shelf software for Space Situational Awareness (SSA). Their platform includes SSASuite, a comprehensive space object catalog, and desktop products such as Spacebook for visualization, SEG for event simulation, and tools for threat assessment. COMSPOC also runs a research center advancing SSA standards and offers data downloads via APIs. The company focuses on delivering actionable space data to support operators, researchers, and policymakers.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for COMSPOC: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
